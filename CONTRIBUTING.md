# Contributing

zKYC Core is maintained by ORDIN. Contributions should preserve the reference implementation's bounded authority-decision scope.

Before proposing a change:

1. open an issue describing the authority or verification requirement;
2. add or update a failing test for behavioral changes;
3. preserve fail-closed behavior for unsupported or contradictory input;
4. run the complete verification bundle;
5. update the evidence map and limitations when the claim boundary changes.

Do not include credentials, private receipts, customer data, payment execution, external-model authority or unrelated UI/product code.

No contribution changes the repository's licensing status unless ORDIN publishes an explicit license file.
