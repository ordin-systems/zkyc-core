## Current canonical owner

ORDIN is the canonical maintainer and public repository owner for this reference implementation.

## Release lineage

- `v0.1.0-reference` is the immutable bounded TypeScript authority-core extraction published on 2026-08-08.
- `v0.2.0-full-stack-reference` is a successor sanitized reconstruction that adds a Hono adapter, TypeScript SDK and React/Vite reviewer cockpit around the core.

The successor release does not rewrite the immutable v0.1 artifact or imply that its new verification evidence existed at the earlier release time. Git history and release timestamps are authoritative.

## Publication boundary

This repository is fresh-history public evidence. It does not preserve or imply the private demo application's full history, production deployment, customer use or third-party adoption. It excludes fixed demo authentication, external-AI authority, webhooks, payment execution, private configuration and unrelated assets.
